# 🪪 Meu Portfólio DB

Portfólio pessoal desenvolvido em React com TypeScript para apresentação de projetos, habilidades e informações profissionais, com interface responsiva (mobile-first) e organização baseada em componentes.

<br>

🔗 Acesse a aplicação: https://rachelpizane-dev.onrender.com/

<br>

## ✨ Principais funcionalidades

- **Seção “Sobre”**: Exibe informações pessoais como nome, cargo atual, foto, descrição e nível de habilidades em desenvolvimento back-end e front-end.
- **Listagem de projetos**: Apresenta projetos em formato de galeria com nome, descrição, tecnologias utilizadas e links para repositório e deploy.
- **Acesso ao currículo**: Permite visualizar o currículo em PDF em uma nova aba diretamente pelo menu.
- **Links de contato**: Disponibiliza acesso rápido ao GitHub, LinkedIn e e-mail pelo cabeçalho da aplicação.
- **Interface responsiva (mobile-first)**: Layout desenvolvido com abordagem mobile-first, adaptando-se de forma fluida para telas maiores.
- **Componentização da interface**: Estrutura baseada em componentes React para organização e separação de responsabilidades.

## 🚀 Como rodar o projeto

### Pré-requisitos

- Node.js (versão LTS recomendada)
- Git

### 1. Clone o repositório

```bash
# Clone o repositório
git clone https://github.com/rachelpizane/db-portfolio.git

# Acesse a pasta do projeto
cd db-portfolio
```

## 2. Instale as dependências

```bash
npm install
```

## 3. Execute a aplicação

```bash
npm run dev
```

<br>

## 🧪 Testes

O projeto possui:

- Testes unitários

Para executá-los:

```bash
npm run test
```

<br>

## 📊 Cobertura de testes

Para gerar o relatório de cobertura:

```bash
npm run test:coverage
```

O relatório será gerado em:

```bash
coverage/index.html
```

Abra o arquivo no navegador para visualizar os detalhes da cobertura.
